## 摘要

面向电商品牌的 ChatGPT Ads 实操指南，建议从真实客户问题出发评估投放，而非先选广告形式。OpenAI 官方 Ads 文档提到网站像素、Conversions API 和 Advertiser API 等衡量工具，但可用性、账户权限与功能可能变化，品牌需先向 OpenAI 确认当前资格。文章还给出 30 天准备计划，强调落地页承接、素材清晰度与投放前先搭好衡量体系。
