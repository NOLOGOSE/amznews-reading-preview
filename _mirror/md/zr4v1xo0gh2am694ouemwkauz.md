## 摘要

与其反复在聊天窗口里写提示词，不如把身份、公司和回复偏好写进 AI 每次会话都会读取的指令文件。这类文件通常是 Markdown 纯文本，Claude Code 读 CLAUDE.md、OpenAI 的 Codex 读 AGENTS.md、Gemini CLI 读 GEMINI.md，内容一致：你是谁、公司做什么、服务谁、希望怎样回答。
