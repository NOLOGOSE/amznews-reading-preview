AGENT SKILL · 1.0.0

装好 Skill，直接问你关心的事

不用记接口，也不用自己写代码。适合 Claude Code、Codex 这类支持 Agent Skills 的工具；Skill 会引导 Agent 读取本站说明，再查询精选、热点和日报，带着来源链接回答。

  1. 1

    把这段话发给你的 Agent

    先确认安装目录，保留已有文件，再安装本站的 Skill。

    安装提示词
    请安装 AMZNEWS Skill：https://nologose.github.io/amznews-reading-preview/amznews-skill/README.md
先读取安装说明，确认你的 Skill 目录；已有同名文件时先告诉我位置和差异，不要直接覆盖。
装完告诉我是否需要开启新会话。
  2. 2

    开一个新会话

    多数 Agent 在会话开始时发现 Skill。安装完成后按客户端提示开启新会话，确认它能看到 AMZNEWS。
  3. 3

    问一句试试

    过去 24 小时亚马逊卖家最值得关注的 5 条资讯是什么？

    回答注明了时间范围、给出中文摘要，并附本站阅读与原文链接，就是接通了。没有新资讯时会如实说明。

装好后可以这样问

  • 最近一周最值得关注的 5 条亚马逊资讯是什么？

  • 亚马逊卖家现在最关注哪些热点？

  • 给我最新一期亚马逊日报。

  • 最近 7 天 FBA 费用或物流有哪些新消息？

  • Amazon Ads 最近有哪些值得关注的更新？

  • 现在最热的那件事，来龙去脉是什么？

已经装过？在原目录更新

把下面这段话发给正在使用它的 Agent，先核对位置与版本。

升级提示词
请检查我已安装的 AMZNEWS Skill，并读取 https://nologose.github.io/amznews-reading-preview/amznews-skill/README.md。
先告诉我原目录、版本和是否有重复副本，再列出需要更新的差异，等我确认后更新原目录。
更新后开启新会话，用“过去 24 小时亚马逊卖家最值得关注的 5 条资讯是什么？”验证。
不装 Skill 也能用
直接查询提示词
请先读 https://nologose.github.io/amznews-reading-preview/llms.txt 和 https://nologose.github.io/amznews-reading-preview/openapi-v1.json，
按公开接口查询：过去 24 小时亚马逊卖家最值得关注的 5 条资讯是什么？
请给出时间范围、中文摘要、站内阅读与原文链接；没有结果就如实说明。
没触发？按这个顺序查
  • 确认客户端支持 Agent Skills，文件确实位于它能发现的目录。
  • 确认 SKILL.md 的名称与完整内容没有被改成网页 HTML。
  • 重新开启会话；必要时明确要求“使用 AMZNEWS 查询”。
  • 确认当前客户端可以访问服务地址；本机预览需要保持 SSH 隧道连接。
目前能查什么，做不到什么
  • 可查精选、最近七天公开动态、热点事件和已经发布的日报；不生成尚未发布的期刊。
  • 只读公开内容，不能修改卖家账户、投放广告或操作订单。
  • 每个新会话首次查询会读取当前接口说明；地址改变或出现不兼容变更时，需要检查并更新 Skill。
  • 站点摘要来自外部信源，重要政策、日期和费用以原文为准。
