Amazon SP-API 与 Amazon Ads API 对比：你需要哪些数据和操作？

亚马逊 SP-API 与 Amazon Ads API 并非可互换的数据源，应按业务对象而非 API 名称选择：零售或供应商运营走 SP-API，广告活动管理与广告报告走 Amazon Ads API，两者都需时须区分指标含义与授权要求。官方资料于 2026 年 9 月 10 日核对，文中数值示例与验收方案仅为演示，非真实账户结果。
