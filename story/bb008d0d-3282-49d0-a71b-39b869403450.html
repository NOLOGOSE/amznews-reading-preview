7 篇报道6 个报道来源4 天前更新

AI 综述

2026年10月，亚马逊宣布推出 Review Requests（评论邀请）广告功能，计划于10月下旬在美国站开放公测，其他站点暂无时间表。该功能通过广告向近期购买者展示原生邀评卡片，买家可一键提交星级评分，也可补充文字、图片或视频；卖家通过 Amazon Ads Agent 或 Unified API 创建和管理活动，竞价与预算控制方式与其他广告一致。适用条件为注册卖家或供应商、广告账户状态良好且无生效中的政策违规，商品累计评分与评论总数须少于1000条，达到门槛后活动自动暂停。关于效果，早先报道称内部封闭测试（2026年6月3日至21日，美国）中参与商品每周获得的评分和评论数量约为测试前的2倍；后续报道称达到测试前的3倍，即增加至原来的两倍以上。关于计费，有报道称采用 CPC 点击付费、未留评也可能产生费用；也有报道称亚马逊尚未公布定价模型，第三方对按点击还是按提交评分计费说法不一。另有报道提到，亚马逊同日一则新闻稿称该功能将于2026年11月上线，未提公测或站点。同期亚马逊还推出 AI 驱动的 Amazon Ads Agent 及全漏斗广告活动等。
